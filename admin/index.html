Innstillinger for kampdata-synk. Hemmelige nøkler ligger i GitHub Secrets — ikke her.

Hva får vi via API?

Aktiv kilde for 2026/27 er football-data.org (gratis). API-Football gratisplan dekker ikke inneværende sesong (kun ca. 2022–2024).

Data Nå (gratis) Hvordan få mer Ca. pris
Premier League-fixtures Ja — €0
Resultater (score) Ja (litt forsinket) Livescores-tillegg fra €12/mnd
Tabell / standings Ja (kan kobles på) — €0
Målscorere Nei football-data Deep Data, eller API-Football Pro ~€29 / ~$19 mnd
Oppstillinger, bytter, kort Nei Deep Data / API-Football Pro ~€29 / ~$19 mnd
Kampstats (possession, skudd, corners) Nei football-data Statistic add-on, eller API-Football Pro ~€15 ekstra / inkl. i Pro
FA Cup / EFL Cup Nei på gratis Betalt football-data-plan, eller API-Football Pro fra ~€49 / ~$19 mnd
Championship-historikk (24/25, 25/26) Ja (CSV, allerede på siden) Spillerstats via API-Football (engangsimport) €0 / API-kall

Synken bruker typisk 1–2 API-kall per mandag (godt innenfor gratisplan). Priser er veiledende — sjekk football-data.org og api-football.com.
